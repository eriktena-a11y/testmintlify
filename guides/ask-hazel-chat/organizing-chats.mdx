---
title: "Organizing chats"
---

As your chat history with Hazel grows, directories help you keep related conversations together — for example, one directory per client household, project, or workstream. Pinned and recent chats still appear in the sidebar timeline; directories give you a second axis for organizing the chats you return to often.

<Info>
  Chat directories are rolling out gradually. If you don't see directories in the Ask Hazel sidebar yet, the feature isn't enabled for your account — it will appear automatically once it is.
</Info>

## Create a directory

1. Open Ask Hazel and look at the chat sidebar on the left.
2. Click **New directory** at the top of the chat list.
3. Type a name (up to 255 characters) and press **Enter** to save, or **Escape** to cancel.

The new directory appears in the sidebar above your timeline of recent chats. Empty directories stay in the sidebar until you delete them, so you can set up a structure before you start filing chats.

## Move a chat into a directory

You can file an existing chat into a directory in two ways:

- **Drag and drop.** Grab a chat row in the sidebar and drop it on the directory you want to file it under.
- **Use the chat menu.** Hover the chat in the sidebar, open the **⋯** menu, choose **Move to directory**, and pick the destination.

Filed chats appear under their directory in the sidebar. Pinned chats inside a directory float to the top of that directory, followed by the rest sorted by most-recent activity.

Filing a chat is purely an organizational move — it doesn't change the chat's last-updated time. Chats keep their place in the Ask Hazel landing page's **Recent chats** list based on when you last interacted with them, whether they live in a directory or not.

## Remove a chat from a directory

To take a chat back out of a directory without deleting it:

- Open the chat's **⋯** menu and choose **Remove from directory**, or
- Drag the chat out of the directory and drop it onto the timeline section of the sidebar.

The chat returns to your timeline (Today, Last 7 days, current month, or older months, depending on when it was last updated).

## Rename a directory

1. Open the **⋯** menu next to the directory name in the sidebar.
2. Choose **Rename**.
3. Edit the name and press **Enter** to save, or **Escape** to cancel.

## Delete a directory

1. Open the **⋯** menu next to the directory name and choose **Delete**.
2. Confirm in the dialog.

<Warning>
  Deleting a directory also permanently deletes every chat inside it. If you want to keep the chats, move them out of the directory first using **Move to directory** or drag-and-drop. The confirmation dialog tells you how many chats will be deleted before you confirm.
</Warning>

## Tips

- Use directories for long-running themes (a specific household, a recurring planning project, a research thread). Leave one-off questions in the timeline.
- Pinning still works inside directories — pin the chat you reference most often so it stays at the top of its directory.
- Search at the top of the sidebar filters across every chat, whether it's filed in a directory or still in the timeline, so you don't have to remember where you put something.
