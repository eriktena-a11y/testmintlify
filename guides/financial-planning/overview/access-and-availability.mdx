You are about to build a plan for a client. Financial planning opens in three places: the **Financial Planning** tab on every household, the **Financial Planning** page in the left nav, and **Ask Hazel** with the chat set to **Financial Planning** mode. A request in plain Ask mode will not start a plan.

## Who can build a plan

Anyone at your firm who can see a household can build a plan for it, with nothing planning-specific to switch on per advisor. A household holds as many plans as you need, each with its own version history.

## Who can open a plan you built

Plans are personal for now, so a colleague with full access still sees the household's **Financial Planning** tab as a household with no plan yet. No permission setting changes this, and shared financial-plan chats are a fast follow. A colleague can build their own plan for the household, leaving yours untouched, and **Export PDF** in the plan's top bar produces the finished document to send to anyone once your changes are saved.

If a colleague cannot see the household at all, that is ordinary household access. See [Roles and permissions](/guides/settings/members/roles-and-permissions).

## What a firm owner sets for everyone

**Settings → Planning** belongs to the firm owner, and everything set there applies to every plan the firm builds. Firm Admin is a separate role that does not include it, so a Firm Admin who cannot find the Planning tab should ask the firm owner to make the change. The sidebar has three groups: **Plan templates**, **Client persona**, and **Assumptions**.

| Setting | Effect |
| --- | --- |
| **Base template** | The blueprint every plan starts from |
| **Plan design** | Which sections, tabs, and blocks a plan has, in what order |
| **Hazel instructions** | Voice, emphasis, and content guidance in your words |
| **Planning assumptions** | Named figures Hazel plans against |
| **Guardrails** | Your never-do rules. Hazel will not cross them, and a persona can add but never remove |
| **Client disclaimer** | The footer under every plan and in the PDF |
| **Client persona** | How the shape and assumptions change by client type |
| **Solver assumptions** | How a projection is run and judged: success threshold, fees, taxes, drawdown |
| **Market assumptions** | Return, volatility, inflation, and tax figures |

**Hazel instructions**, **Planning assumptions**, and **Guardrails** are blocks inside the **Base template** card; **Plan design** and **Client disclaimer** are cards of their own below it. Everything saves as you go.

<Warning>
  The **Client disclaimer** box shows wording Hazel has drafted for you, but it is not applied until you edit the box yourself, so a firm that never opens it publishes plans with no footer. Set yours before the first client-facing export. Hazel reads the disclaimer fresh each time a plan opens, so an edit reaches earlier plans too.
</Warning>

Advisors who are not firm owners never see these panels, though every plan they build follows them. A bookmarked link to the plan design editor opens, then reports that they cannot reach it. They can still read the [Applied settings block](/guides/financial-planning/your-data/where-numbers-come-from) in the plan's **Appendix**, which tags each setting with the layer that set it.

<Note>
  An advisor can still tune a single plan. **Plan settings** is a chat-view control, so from a household's **Financial Planning** tab, **Open chat** takes you there first. The override belongs to that one plan, and other plans for the household still inherit the firm and persona values. See [Solver assumptions](/guides/financial-planning/assumptions/solver-assumptions).
</Note>
